# Exemple JavaScript (Express)

Ce dossier contient un exemple Express.js montrant l'intégration de VLogger.

Pré-requis
- Node.js

Installer et démarrer :

```bash
npm install express
node app.js
```

Le serveur écoute par défaut sur `http://localhost:3000`.
Le dashboard VLogger est attendu sur `http://localhost:3333`.

Endpoints utiles : `GET /`, `GET /users`, `POST /users`, `GET /error`, `GET /slow`.
